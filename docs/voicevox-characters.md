## 調べ方

VOICEVOX エンジンの `/speaker_info` は、キャラごとの利用規約の要約を内蔵している。
これを43キャラ分すべて取得して仕分けた（`.cache/policies/` に全文を保存）。
要約は権利者本人が書いたものなので一次情報に近いが、**要約であって本文ではない**。
そこで、実際に使う可能性の高い権利者については本文も当たった。

再取得するには:

```
python - <<'EOF'
import json, urllib.request, urllib.parse
E = 'http://127.0.0.1:50021'
for s in json.load(urllib.request.urlopen(E + '/speakers')):
    q = urllib.parse.urlencode({'speaker_uuid': s['speaker_uuid'], 'resource_format': 'url'})
    print(s['name'], json.load(urllib.request.urlopen(E + '/speaker_info?' + q))['policy'])
EOF
```

## 結論

**A群 37キャラは、クレジット表記だけで企業でも使える。**
B群4キャラは企業が関わるなら事前確認が要る。C群2キャラは非商用のみ。

| 群 | 数 | 条件 |
|---|---|---|
| **A** | 37 | クレジット表記のみ。企業・法人の門番なし |
| **B** | 4 | 企業・法人・個人事業主が関わる場合は事前確認が必要 |
| **C** | 2 | 非商用のみ（同人・配信収入は可）。商用は個別許諾 |

## この番組で気にすべき禁止事項

ずん子系は**宗教活動**が、つむぎは**特定の思想・団体に関係するもの**が禁止されている。

第001回は二十六聖人の殉教、つまりキリスト教史を扱う。これは史実の解説であって
布教でも特定団体の推進でもないので通常は問題にならないと考えるが、
宗教・政治が絡む題材を扱う回では、採用キャラの禁止事項を都度読み直すこと。
