最終更新: 2026-09-15

## コンセプト

〒または町名を指定すると、その町の遺構・歴史建造物・地名の由来にまつわる
「碑」の話を集め、読み上げシナリオを作り、VOICEVOX で動画にする。

## 話者構成（2人の掛け合い）

| 役 | 役割 | 既定の VOICEVOX 話者 | 口調 |
|---|---|---|---|
| 探訪役 | 現地を歩き、素朴に驚き、問いを投げる | 春日部つむぎ（ノーマル） | 敬体・明るい・短い |
| 案内人 | 地形と歴史を解きほぐし、答えを出す | 雀松朱司（ノーマル） | 敬体・落ち着き・やや講義調 |

- 掛け合いの型: 探訪役が「気づく」→ 案内人が「なぜそうなのか」を地形・歴史で説明

- 採用キャラの利用規約は**キャラ単位で個別確認**すること（VOICEVOX はキャラごとに

- 案内人は 玄野武宏 → 青山龍星 → 雀松朱司 と変えた。玄野武宏はノーマルの抑揚が平坦で

  声の比較でも次点だったのでそのまま置き換えた。詳細は docs/voicevox-characters.md。

## 1本の構成

- **2〜4話の可変**。調査で「いい話」が何本取れたかで決める。既定の狙いは 3 話。
- 1話 2.5〜3分 → 全体 6〜10分程度。
- 話ごとの型:
  1. 現地の違和感（坂・カーブ・不自然な区画など、いま見えるもの）
  2. 地形／歴史による説明（地理院タイルのレイヤで見せる）
  3. 碑の登場と碑文の中身
  4. いまに残る痕跡への着地

## 台詞の書き方

- **西暦は算用数字で書く**（`1597年`）。字幕にそのまま出るので、漢数字だと読みにくい。
  VOICEVOX の読みは漢数字と完全に一致することを実測済み（`/audio_query` の kana を比較）
  なので、表示の都合だけで選んでよい。
- 年数・人数・順序など西暦でないものは漢数字のまま（`六年後` `七年` `二十六聖人`）。
### 読みの補正

VOICEVOX は地名と熟語をよく外す。直し方は2通りあり、**使い分けを間違えると別の語を壊す**。

1. **全体に効かせる** — `tools/readings.json` に語を足して `python tools/readings.py apply`。
   町名など、どこに出ても同じ読みでよい語はこちら。`priority` は 10 固定
   （既定の 5 では文中で組み込み辞書に負け、単語単体では直って見えるのに
   台詞にすると元に戻る）。
2. **その場だけ効かせる** — script.md に `碑《ひ》` と書く。
   字幕は「碑」、読み上げは「ひ」になる。複合語を巻き添えにしたくないときはこちら。
3. **ひらがなに開く** — script.md の漢字そのものを かな で書く。
   単漢字で読みが割れる語（方・他・間 など）はこれ。辞書に入れると、
   どちらの読みも正しいので必ず片方を壊す。「〜のかた」「〜のほか」のように
   前後を含めて登録しても、その並びだけしか直らず、次の回でまた踏む。
   放送の表記でも人を指す「〜のかた」はかな書きが標準なので、字幕も自然になる。


**補正したら必ず `python tools/readings.py diff` を見ること。**
readings.json の `guard` に並べた語の読みを補正前後で比べ、変わったものを全部出す。

実例: 「碑」が イシブミ と読まれるので ヒ を辞書登録したら、「石碑」が
セキヒ → イシヒ に壊れた。石碑・記念碑も登録して読みは戻ったが、今度は
「日本二十六聖人記念碑」のアクセント核が動いた。結局 辞書はやめて
script.md 側で `碑《ひ》` と 9 か所に書くことで解決した。

**語単位で見ても足りない。台詞を 1 行ずつ、文章と読みを並べて読むこと。**
`python tools/readings.py suspects <ep_dir>` は漢字語を総ざらいするが、
語を単独で読ませるので、文脈で決まる読みは拾えない（「日本の方」の 方 は
単独なら ホウ と読めてしまう）。`scan <ep_dir>` は台詞を丸ごと読ませて
文章と並べて出すので、そこで初めて見つかるものがある。第002回では
アーチ橋→アアチキョオ・同じ人→ドオジジン・降りました→オリマシタ が
これで出た。どれも語だけ見れば正しく読めていた。
