# 番組フォーマット（決定事項）

最終更新: 2026-09-15

参考番組: [ブラタモリ](https://ja.wikipedia.org/wiki/ブラタモリ)

## コンセプト

〒または町名を指定すると、その町の遺構・歴史建造物・地名の由来にまつわる
「碑」の話を集め、読み上げシナリオを作り、VOICEVOX で動画にする。

## 話者構成（2人の掛け合い）

| 役 | 役割 | 既定の VOICEVOX 話者 | 口調 |
|---|---|---|---|
| 探訪役 | 現地を歩き、素朴に驚き、問いを投げる | 春日部つむぎ（ノーマル） | 敬体・明るい・短い |
| 案内人 | 地形と歴史を解きほぐし、答えを出す | 雀松朱司（ノーマル） | 敬体・落ち着き・やや講義調 |

- **口調・話者はエピソードごとに都度確認する。**上表は確認を省いたときの既定値。
- 掛け合いの型: 探訪役が「気づく」→ 案内人が「なぜそうなのか」を地形・歴史で説明
  → 探訪役が驚く → 案内人が碑につなげて締める。
- 採用キャラの利用規約は**キャラ単位で個別確認**すること（VOICEVOX はキャラごとに
  規約が異なる）。動画の概要欄に `VOICEVOX:春日部つむぎ` 形式でクレジットを記載。
- 案内人は 玄野武宏 → 青山龍星 → 雀松朱司 と変えた。玄野武宏はノーマルの抑揚が平坦で
  棒読みに聞こえた。青山龍星は声は良かったが、企業・個人事業主が関わる利用には
  ななはぴへの事前申請が必要（B群）。雀松朱司は同じ VirVox Project で門番がなく、
  声の比較でも次点だったのでそのまま置き換えた。詳細は docs/voicevox-characters.md。

## 1本の構成

- **2〜4話の可変**。調査で「いい話」が何本取れたかで決める。既定の狙いは 3 話。
- 1話 2.5〜3分 → 全体 6〜10分程度。
- 話ごとの型:
  1. 現地の違和感（坂・カーブ・不自然な区画など、いま見えるもの）
  2. 地形／歴史による説明（地理院タイルのレイヤで見せる）
  3. 碑の登場と碑文の中身
  4. いまに残る痕跡への着地

## テーマ（3カテゴリ）

町を指定したとき、その町で作れる回は素材の種類で決まる。いまのところ3つある。
`episode.json` の `theme` に入れる。

| テーマ | 芯になるもの | 引けるデータ | 効く地図 |
|---|---|---|---|
| **石碑** | 碑に刻まれた文 | 地理院 自然災害伝承碑（2,469基・碑文と座標つき） | 淡色地図・陰影起伏図 |
| **土木** | 人が作った巨大なもの | 土木学会 選奨土木遺産（約500件・所在地から座標化） | 旧版空中写真・傾斜量図 |
| **史跡** | 遺構と発掘 | 文化庁 国指定文化財等データベース | 傾斜量図・陰影起伏図 |

**テーマが変わると、カメラの動く向きが変わる。**
石碑は町を横に振る（碑から碑へ歩く）。土木は1点に寄って時間へ潜る
（同じ画角のまま 1961年 → 1974年 → 現在 をクロスフェードする）。
ショットの `layers` に同じ画角で複数の空中写真を積み、`alpha` を時間で動かす。
先頭のレイヤが下地で alpha は無視されるので、いちばん古い年を先頭に置く。

**空中写真は年代ごとに整備範囲が違う。**長崎県で実測したところ、
1961〜69年・1974〜78年・現在はどこでも揃い、1945〜50年は市街地だけ、
1984〜86年は全滅だった。山岳部は逆に現在のオルソが無い。
シナリオに年代を書く前にタイルの存在を確かめること。

**最新のオルソには撮影時期の継ぎ目が入る。**シームレス空中写真でも同じ
（元画像が同じなので）。継ぎ目の緯度を測って、カメラの中心をずらして
画面の端へ逃がす。第003回では敷地の中央を横切っていたので、
中心を約70m南へ振った。

## 形式（style）

テーマが「何を扱うか」なら、形式は「どう見せるか」。別の軸なので掛け合わせる。
`episode.json` の `style` に入れる。

| 形式 | 組み立て |
|---|---|
| **対話** | 探訪役が訊き、案内人が答える。第001・002回 |
| **クエスチョン** | 案内人が出題し、間を置いて探訪役が答え、正解が出る。第003回 |

クエスチョン形式でも**話者は増やさない**。いまの探訪役がそのまま解答者になる。
素朴に驚く役と地続きなので、役が濁らない。各話に1問が目安。

**書き方**

```
朱司｜さて、ここでクエスチョンです。
朱司｜この塔は、3本あります。なぜ、3本も必要だったのでしょうか。
間｜3.2
つむぎ｜……大きいから、倒れないように支え合ってる？
朱司｜それが、違うんです。
```

`間｜3.2` が考える時間の無音。**行そのものは増えず、次の台詞の前の間になる。**
行を増やすと台詞番号が全部ずれて、shots.py の `T(n)` がまとめて壊れるため。

札は `shots.py` で `question(["問い"], 問いの行, 答えの行)` と書く。
考える時間は `TE(問いの行)` 〜 `T(その次の行)` で取れるので、秒数を二重に書かない。
残り時間のバーがそこに引かれる。**無音が続く理由が画で分かるようにするため。**

BGM のダッキングは語りに反応するので、考える時間では自然に BGM が戻る。
ここは何もしなくてよい。

**台詞を書き換えたら台詞番号がずれる。**shots.py を手で直すと必ず取りこぼす。
旧と新の timeline.json を本文で突き合わせて対応表を作り、`T(n)`/`TE(n)` を
機械で置換すること。消えた行を指していた参照だけが残るので、そこは手で寄せる。

## 台詞の書き方

- **西暦は算用数字で書く**（`1597年`）。字幕にそのまま出るので、漢数字だと読みにくい。
  VOICEVOX の読みは漢数字と完全に一致することを実測済み（`/audio_query` の kana を比較）
  なので、表示の都合だけで選んでよい。
- 年数・人数・順序など西暦でないものは漢数字のまま（`六年後` `七年` `二十六聖人`）。
### 読みの補正

VOICEVOX は地名と熟語をよく外す。直し方は2通りあり、**使い分けを間違えると別の語を壊す**。

1. **全体に効かせる** — `tools/readings.json` に語を足して `python tools/readings.py apply`。
   町名など、どこに出ても同じ読みでよい語はこちら。`priority` は 10 固定
   （既定の 5 では文中で組み込み辞書に負け、単語単体では直って見えるのに
   台詞にすると元に戻る）。
2. **その場だけ効かせる** — script.md に `碑《ひ》` と書く。
   字幕は「碑」、読み上げは「ひ」になる。複合語を巻き添えにしたくないときはこちら。
3. **ひらがなに開く** — script.md の漢字そのものを かな で書く。
   単漢字で読みが割れる語（方・他・間 など）はこれ。辞書に入れると、
   どちらの読みも正しいので必ず片方を壊す。「〜のかた」「〜のほか」のように
   前後を含めて登録しても、その並びだけしか直らず、次の回でまた踏む。
   放送の表記でも人を指す「〜のかた」はかな書きが標準なので、字幕も自然になる。


**補正したら必ず `python tools/readings.py diff` を見ること。**
readings.json の `guard` に並べた語の読みを補正前後で比べ、変わったものを全部出す。

実例: 「碑」が イシブミ と読まれるので ヒ を辞書登録したら、「石碑」が
セキヒ → イシヒ に壊れた。石碑・記念碑も登録して読みは戻ったが、今度は
「日本二十六聖人記念碑」のアクセント核が動いた。結局 辞書はやめて
script.md 側で `碑《ひ》` と 9 か所に書くことで解決した。

**語単位で見ても足りない。台詞を 1 行ずつ、文章と読みを並べて読むこと。**
`python tools/readings.py suspects <ep_dir>` は漢字語を総ざらいするが、
語を単独で読ませるので、文脈で決まる読みは拾えない（「日本の方」の 方 は
単独なら ホウ と読めてしまう）。`scan <ep_dir>` は台詞を丸ごと読ませて
文章と並べて出すので、そこで初めて見つかるものがある。第002回では
アーチ橋→アアチキョオ・同じ人→ドオジジン・降りました→オリマシタ が
これで出た。どれも語だけ見れば正しく読めていた。

## 映像

- **第1段階: 地図主役**。地理院タイルのパン／ズーム／レイヤ切替を主体に、
  写真は差し込み。全自動化しやすく権利も明快。
- **第2段階: 3D を足す**。基盤地図情報 DEM → Blender の地形立体化、
  PLATEAU の街並み。パイプラインが1本通ってから着手する。
