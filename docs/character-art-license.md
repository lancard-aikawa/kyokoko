# 立ち絵を企業が使えるか

調査日: 2026-09-15

## 結論

**調べた範囲では、立ち絵を企業が自由に使えるキャラは見つからなかった。**

VOICEVOX 系のキャラクターには、はっきりした構造がある。

> **音声は法人フリー。キャラクター（立ち絵・イラスト）は法人は要許諾。**

権利者は音声を「広めてほしいもの」、キャラクターを「管理したい資産」として
別々に扱っている。だから音声の規約がどれだけ緩くても、立ち絵で詰まる。

とくに **「このプログラムでこんな動画が作れます」と見せる用途**は、
他のコンテンツの宣伝手段としての利用にあたり、ほぼ確実に許諾が要る。

離途の規約がいちばん分かりやすい。音声とキャラクターを1行ずつ並べて、
音声は法人無料・キャラクターは法人要許諾、とはっきり書いている。

## あいえるたんについて

5件のうち唯一、立ち絵に法人・営利の制限が書かれていない。株式会社インフィニットループが
自社キャラとして配布しているもので、音声の許可範囲も「テレビ番組、ラジオ番組、
機器への組み込み」まで含んでおり、商業利用を前提にした設計に見える。

**ただし「書かれていない」は「許可されている」ではない。**
企業として使うなら、先方に一度確認するのが確実。禁止事項に
「弊社および弊社関連製品のような誤解を招く形で使用すること」があるので、
自社の宣伝に使う場合はそこの線引きも聞いておきたい。

規約: https://www.infiniteloop.co.jp/special/iltan/terms/

## 取りうる道

| 道 | 確実さ | 手間 |
|---|---|---|
| **立ち絵なしで作る**（既定） | 確実 | ゼロ。既定がこれ |
| **オリジナルの立ち絵を用意する** | 確実。制約ゼロ | 発注か自作 |
| **あいえるたんに問い合わせて確認を取る** | 確認が取れれば確実 | メール1通。ただし女性キャラ1体なので相方は別途 |
| 立ち絵は使う人が各自で用意する部品とする | 配布物としては確実 | 設計としてはこれが正しい |

この番組は地図と写真とナレーションで成立しているので、立ち絵を外しても
作品としては崩れない。**そこで既定を「立ち絵なし」にした。**

    python tools/build.py all            立ち絵なし（既定）
    python tools/build.py all --chara    立ち絵あり（個人の作品として出すとき）

立ち絵を足したい人は `episodes/*/chara/` に自分で用意した PNG を置いて
`--chara` を付ける。プログラムは受け口だけを持ち、素材は持たない。

## 元データの扱い

立ち絵の元データ（Live2D モデル・PSD）はどれも**二次配布禁止**。
書き出した PNG も派生物なので、リポジトリやアーカイブに含めて人に渡すと
二次配布にあたる。`episodes/*/chara/` の中身は配らないこと。
