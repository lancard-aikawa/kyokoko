# 回のファイル構成

最終更新: 2026-09-17

`episodes/<番号>-<slug>/` の中身と、それぞれの書式。**雛形は
`python tools/new.py` が作る**ので、ここは「何を書き換えるか」を読むための文書。

| ファイル | 誰が書くか | git に入るか |
|---|---|---|
| `episode.json` | 人（ブラウザUI も読み書きする） | ○ |
| `research.md` | 人。雛形は作らない | ○ |
| `script.md` | 人 | ○ |
| `shots.py` | 人 | ○ |
| `photos.json` | `tools/photos.py` が書く | ○ |
| `photos/` | `tools/photos.py` が入れる | ○ |
| `chara/` | 人が置く。**中身は配らない**（二次配布禁止の素材） | × |
| `out/` | `tts.py` と `build.py` の生成物 | × |

## 作る順番

```
python tools/new.py 006 isahaya-ikiriki "諫早市 多良見町伊木力"
                                        ↓ 雛形ができる（そのままビルドできる）
調べて research.md を書く
script.md を書き換える
python tools/readings.py suspects <ep_dir>   漢字語を総ざらい
python tools/readings.py scan     <ep_dir>   行ごとの読みを目で追い、声にも出す
python tools/readings.py check    <ep_dir>   機械で止める（誤読があれば終了コード1）
python tools/tts.py <ep_dir>                 合成。out/timeline.json ができる
shots.py を書く（台詞番号は timeline.json に出ている）
python tools/build.py --ep <ep_dir> check    構図を1枚ずつ確認
python tools/build.py --ep <ep_dir> all      本編
```

**`shots.py` は `timeline.json` ができてから書く。**時刻を台詞番号から引くので、
先に合成しておかないと番号が分からない。

## episode.json

企画。回の上流にあたる決めごとを集める。

| キー | |
|---|---|
| `id` | フォルダ名と同じ（`006-isahaya-ikiriki`） |
| `program` | 番組名。タイトルカードには出ない（出るのは `shots.py` の `title.main`） |
| `town.name` | 町の呼び名。ギャラリーの見出しに出る |
| `town.postal` | 〒。無くてもよい |
| `town.center` | `[緯度, 経度]`。`new.py` が住所検索から入れる |
| `town.note` | この回の芯。あとで読み返すためのメモ |
| `title` | 回の題。ギャラリーとタイトルカードの副題に出る |
| `mood` | 調子と方針。断定しないこと・伏せること・数字の扱い |
| `cast` | 話者ごとの設定。下の表 |
| `chapters` | 話の一覧。`n` が話番号で、`0`=アバン / `99`=エンディング |
| `timing` | 間の秒数。下の表 |
| `bgm` | 既定の曲・音量・ダッキング・クレジット |
| `theme` | 石碑 / 土木 / 地形 / 史跡（`docs/format.md`） |
| `style` | 対話 / クエスチョン（同上） |

**`cast.<話者名>`**

| キー | |
|---|---|
| `speaker` | VOICEVOX の話者番号。**エンジンのバージョンで変わりうる**ので、別の環境で使うときは `label` と合っているか確かめる |
| `label` | 「春日部つむぎ / ノーマル」のような人が読む名前 |
| `role` / `tone` | 役と口調。書くときの指針で、合成には効かない |
| `color` | 字幕の話者名の色 `[R, G, B]` |
| `side` | 立ち絵を出す側（`left` / `right`） |
| `speedScale` / `intonationScale` / `pitchScale` | VOICEVOX にそのまま渡す |
| `credit` | 概要欄に出すクレジット |

**`timing`**（秒）

| キー | |
|---|---|
| `lead_in` | 話の頭の無音 |
| `tail` | 話の尻の無音 |
| `gap_same` | 同じ人が続けて喋るときの間 |
| `gap_switch` | 話者が替わるときの間 |
| `gap_cut` | カット（`###` の見出し）をまたぐときの間 |

## script.md

台本。**`tts.py` が拾うのは台詞行だけ**で、見出しや地の文は無視される。

### 台詞行

```
話者名｜台詞
```

区切りは**全角の縦棒**。話者名は `episode.json` の `cast` のキー。

```
つむぎ｜みかん畑ですね。ずっと段々になってる。
朱司｜諫早市の多良見町、伊木力というところです。
```

### カットの区切り

`### ` で始まる見出しがカットの境目になり、そこで `gap_cut` の間が入る。
見出しの文言は自由（`### カット1-1 二つの海` のように書いている）。

### 考える時間

```
朱司｜長崎を出てから帰ってくるまで。何年かかったでしょうか。
間｜3.2
つむぎ｜えっと……三年？
```

`間｜N.N` は**行として数えられない。**次の台詞の前の無音になるだけ。
行を増やすと台詞番号が全部ずれて `shots.py` の `T(n)` がまとめて壊れるため。

### ふりがな（ルビ）

```
朱司｜記録的な雨が降《ふ》りました。
つむぎ｜奥さんの棺《ひつぎ》から。
```

字幕は漢字のまま、読み上げだけ かな になる。ルビの範囲は**漢字・カタカナの
連なりだけ**（`([一-鿿゠-ヿ々〆ヶ・ー]+)`）。地の文まで飲み込むと字幕と読みが
食い違う。アクセント核を指定したいときは `碑《ひ^1》`。

### 読みの直し方は3通り

| | 使うとき |
|---|---|
| `tools/readings.json` に登録 | どこに出ても読みが同じ語（地名・人名・熟語） |
| ルビ `碑《ひ》` | その場だけ。複合語を巻き添えにしたくないとき |
| かなで書く | 単漢字で読みが割れる語（方・他・間・表・上） |

くわしくは `docs/format.md` の「読みの補正」。**`readings.json` を直すと
指紋が変わるので、その回の全行が録り直しになる。**

## shots.py

ショットの構図。`build(timeline)` を持つことだけが約束で、
`{話番号: [ショット, ...]}` を返す。

```python
def build(timeline):
    S = {r["index"]: r["start"] for r in timeline}
    E = {r["index"]: r["end"] for r in timeline}
    T = lambda i, d=0.0: S[i] + d      # 行の頭
    TE = lambda i, d=0.0: E[i] + d     # 行の尻
    ...
    return {0: ep0, 1: ep1, 2: ep2, 99: end}
```

**時刻は秒で直書きしない。**台詞番号から引けば、録り直して尺が動いても
構図が自動で追従する。`index` は**回の全体で通した1始まりの番号**で、
話ごとには戻らない。時刻は**その話の中の秒**（話の頭が 0 秒）。

各話の最初のショットは `0.0` から始め、最後は `TE(最終行, 0.9)` で終える
（`tail` の 0.9 秒と合わせて音声の全長にそろえる）。

### 地図のショット

| キー | |
|---|---|
| `t0` / `t1` | 始まりと終わりの秒 |
| `zoom` | 地理院タイルのズーム |
| `camera` | `[[時刻, 緯度, 経度, scale], ...]` を補間する。`scale` は大きいほど引き |
| `layers` | 重ねるレイヤ。**先頭が下地で `alpha` は無視される** |
| `labels` | 地図上の点と名前 |
| `notes` | 画面左上の札 |
| `paths` | 線を引く（`points` を時間で伸ばす） |
| `title` | タイトルカード |
| `question` | クエスチョンの札 |
| `credits` | エンディングのクレジット |

`layers` の要素は `{"id": "pale"}` か `{"id": "swale", "alpha": [[t, 0.0], [t2, 0.8]]}`。
使える `id` は `tools/tiles.py` の `LAYERS`。

### 写真のショット

```python
photo("First_Japanese_Embassy_to_Europe_1586_png.png", T(26), T(33),
      kb=[[T(26), 1.06, 0.50, 0.50], [T(33), 1.20, 0.50, 0.47]])
```

`type: "photo"` を持つ辞書。キーは `photos.json` のキー。
`kb` は `[時刻, 拡大率, 中心x, 中心y]`（x/y は 0〜1）。
**`kb` の最大拡大率から余裕を計算しているので、あとから大きい値を足すと
crop が画像からはみ出して PIL が黒で埋める**（例外は出ない）。

### ズームは地上の広さから決める

緯度33度あたり、画面 1920px に入る横幅。

| z12 | z13 | z14 | z15 | z16 | z17 |
|---|---|---|---|---|---|
| 62km | 31km | 15km | 7.7km | 3.8km | 1.9km |

`camera` の `scale` がここに掛かる。**レイヤごとに使えるズーム範囲が違う**
（`tiles.LAYERS`）。下限より低いズームを頼むと切り上げられて欠測が黒く出る。
上限より高いと切り下げてから拡大されるので、静かにぼやける。
`slopemap` と `relief` は上限 15。

### タイトルとラベルは重ならない

`clip.title_active` が**タイトルが出ている間だけラベルと注記を伏せる**。
ラベルは画面中央付近に出るので、そうしないと番組名と重なる。
ショットを割る必要はない。

## photos.json

`tools/photos.py get` が書く。**手で書かない。**

```json
{
  "<保存名>": {
    "file": "Commons のファイル名", "license": "CC0",
    "author": "...", "credit": "...", "url": "...", "page": "...",
    "width": 3000, "height": 2000, "path": "photos/<保存名>"
  }
}
```

**ライセンスは権利の根拠なので消さない。**この企画は CC0 / PD / CC BY /
Attribution だけを使い、**CC BY-SA は避けている**（`docs/sources.md`）。
エンディングのクレジットはこの中身から組み立てられる。

## research.md

調査メモ。雛形は作らない。実際に書いているのは次のあたり。

- なぜこの町・この題材か（他の回との関係）
- 位置（緯度経度と、その出どころ）
- 年表と数字（出典つき）
- 絵（どのタイル層が実際に使えるか。**叩いて確かめた結果**）
- 写真（使えるもの／ライセンスで使えないもの）
- 読みの下ごしらえ
- 扱い方の方針（断定しないこと）
- まだ確かめていないこと
- 出典

既存の回が見本になる。`episodes/005-isahaya-ikiriki/research.md` がいちばん詳しい。
