# 第004回 諫早 —「水が出られない土地」 調査メモ

テーマ: **地形**（4つ目のカテゴリ。土地そのものが芯）

## なぜここか

第002回（長崎の眼鏡橋）と**完全な対になる題材が見つかった**。

| | 第002回 長崎の眼鏡橋 | この回 諫早の眼鏡橋 |
|---|---|---|
| 架けた年 | 1634年 | **1839年**（長崎のを参考にした） |
| 狙い | 流されないため | **流されないため**（同じ） |
| 水害 | 1982年 長崎大水害で**流された** | 1957年 諫早大水害で**壊れなかった** |
| その後 | 石を拾い集めて**元の場所に**架け直した | **流木をせき止めて被害を拡大した**と指摘され、爆破解体案が出た |
| いま | 中島川に架かっている | **諫早公園の池**に架かっている（川ではない） |

**流された橋は元の場所に戻り、流されなかった橋は場所を失った。**
これがこの回の芯になる。そしてそこから「なぜ諫早は水に弱いのか」＝地形の話へ落ちる。

## 諫早眼鏡橋

| | |
|---|---|
| 架橋 | 1839年（天保10年）。佐賀藩重臣の諫早家が本明川に架けた |
| 狙い | 「水害でも流されない頑丈な橋」。**長崎の眼鏡橋を参考にしたとされる** |
| 規模 | 長さ 49.25m / 高さ 7m / 幅 5.5m / 石造二連アーチ / **約2,800個の石** |
| 1957年 | 欄干の一部が損傷しただけ。ただし**せき止めた流木やがれきが水の流れを変え、被害を拡大したとの指摘** |
| 復興案 | 川幅拡張に合わせて**爆破解体する案**が出た |
| 保存 | 当時の野村儀平市長らが働きかけ、**1958年に日本の石橋として初めて国の重要文化財に指定** |
| 移設 | 1959〜1960年に諫早公園へ |

長崎の眼鏡橋は約831個（第002回で使った数字）。諫早は2,800個で、3倍以上ある。

## 1957年 諫早大水害

- 死者・行方不明 **580人以上**
- 本明川の氾濫

※ 日付・時間雨量などの細部は未確認。第002回の長崎大水害（1982年7月23日・
　 一時間187mm・碑文の262人）と同じ密度で書くなら、一次資料に当たること。
　 国土交通省 長崎河川国道事務所と、自然災害科学の論文（2017年・36巻3号）がある。

## なぜ諫早は水に弱いのか（地形）

- **有明海は日本一の干満差**（最大で約6m）と日本一の干潟面積（国土技術政策総合研究所の資料）
- 満潮時は川の水が海へ出られない。そこへ雨が来ると逃げ場がなくなる
- 本明川は短く、流域が山からすぐ海に落ちる

第002回の長崎が「すり鉢の底に雨水が集まる」だったのに対し、
諫早は「**出口が潮で塞がる**」。同じ水害でも理由が違う。ここが地形テーマの見せ場。

## 開門問題 — 決着の仕方をそのまま書く

相反する判決が並んだ時期があり、これを「ねじれ」と呼んだ。

| 年月 | |
|---|---|
| 2008年6月 | 佐賀地裁 5年開放命令 |
| 2010年12月 | 福岡高裁 **5年開放が確定**（上告見送り） |
| 2013年11月 | 長崎地裁 **開門差し止め**の仮処分 |
| 2014年 | 佐賀地裁「開門しなければ制裁金」／長崎地裁「開門すれば制裁金」 |
| 2015年1月 | 最高裁 **両方の制裁金とも有効** |
| 2019年6月 | 最高裁「開門せず」 |
| 2022年3月 | 福岡高裁 開門命令の効力を無効化 |
| **2023年3月1日** | **最高裁が無効化を認可。「非開門」で統一** |

**扱い方の方針。**第002回で水害の死者を、第003回で「ニイタカヤマノボレ」の
真偽を扱ったのと同じにする。

- 事実は事実として置く。数字と年月日を出す
- **どちらが正しいかは言わない。**「開門すれば制裁金、開門しなければ制裁金」という
  状態が実際に存在したこと自体が、この話のいちばん強い事実
- 漁業者・営農者のどちらの側にも立たない。地形の話に戻す
- 「いまも争っている」ではなく「2023年に非開門で統一された」と、決まったことは決まったと書く
