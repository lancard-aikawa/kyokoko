# 第006回 横浜 神奈川台場 —「陸になった台場」

- 話者: 探訪役＝春日部つむぎ（ノーマル）／案内人＝雀松朱司（ノーマル）
- アバン＋全3話＋エンディング
- テーマ: **石碑**（石柱と石垣）。見せ方は**変遷**: 同じ画角で明治の海 → 1945〜50年 → いま、と差し替える
- 形式: **クエスチョン**（各話に1問。出題は朱司、解答はつむぎ）
- トーン: 第001〜005回と同じ。**「勝海舟の設計」は市史の言葉として引き、地の文で言い切らない。**
  費用・面積は資料で割れるので、割れていると言うか、言わない。
  2026年の発掘が記録保存になったことは、良し悪しを言わずに事実だけ置く。
  攻める・守るの当否には立ち入らず、土地の形の話に戻す。

台詞行の書式: `話者名｜台詞`（全角縦棒区切り。TTS はこの行だけを拾う）
話者名は つむぎ / 朱司。ふりがなは `碑《ひ》`、考える時間は `間｜3.2`。
くわしくは docs/episode-files.md。数字の出どころは research.md の年表。

## アバン

線路の脇の石垣から引く。

### カット0-1 線路の脇

写真: File:Kanagawa-daiba Stone wall.jpg（石垣の寄り）

つむぎ｜大きな石が、斜めに積んでありますね。
朱司｜横浜市の神奈川区、東神奈川の駅から南へ八百メートルほどです。
つむぎ｜お城の石垣みたいですね。でも、まわりは家ばかりです。
朱司｜すぐ横は、貨物の線路です。

### カット0-2 石柱

写真: File:Kanagawa-daiba.jpg（石柱と説明板）

つむぎ｜あ、石の柱が立っています。「史跡 神奈川台場跡」と書いてありますね。
朱司｜台場。大砲を据えるための場所です。
つむぎ｜大砲ですか。こんな住宅地の中に置いてあったんですか。
朱司｜いまは住宅地ですが、造ったときは、ここは海の中でした。
つむぎ｜海の中に大砲を置いたんですか。どうやって置いたんでしょう。
朱司｜今日は、この石垣が海から陸へ移っていくのを、順に見ていきます。

## 第1話 海に築く

### カット1-1 明治の海

地図: 標準地図 z16 に 明治期の低湿地（swale）を重ねる / 石柱を中心に

朱司｜明治のころの海岸線を、いまの地図に重ねてみます。水色が、当時の海です。
つむぎ｜線路も家も、半分くらい水色の中ですね。
朱司｜その海の中に、白く残っている形があります。
つむぎ｜陸から、ぽこっと海へ突き出していますね。
朱司｜これが神奈川台場です。さっきの石柱は、この形の縁《ふち》に立っています。

### カット1-2 開港の翌月

地図: 淡色地図 z14 / 神奈川宿の海岸と横浜の開港場を一枚に

朱司｜横浜が開港したのは、1859年の7月1日です。
つむぎ｜外国の船が、どんどん来るようになったころですね。
朱司｜この海沿いの警備を任されていたのが、伊予の松山藩でした。
つむぎ｜四国の藩が、ここの警備をしていたんですか。
朱司｜工事が始まったのは、開港の翌月、1859年の8月18日です。
つむぎ｜開港して、すぐに取りかかったんですね。

### カット1-3 勝麟太郎

地図: 淡色地図 z15 / 台場の形（swale）を重ねたまま

朱司｜昭和のはじめに横浜市がまとめた市史には、こう書かれています。
朱司｜品川の台場は造りが不十分だという評判があったので、松山藩は、幕府の勝麟太郎に託すことにした。
つむぎ｜勝麟太郎って、勝海舟ですか。
朱司｜そうです。市史は、勝《かつ》が門人を連れて現地に来て、杭を打って縄を張ったのは主に門人だった、とも書いています。
つむぎ｜勝海舟《かつかいしゅう》が設計した台場、なんですね。
朱司｜市史はそう伝えています。ただ、勝《かつ》自身が書いた記録では、まだ確かめられていません。

### カット1-4 山を削る

地図: 陰影起伏図 z16 / 石柱から西の台地（権現山）まで

朱司｜海の中に陸を作るには、土が要ります。
つむぎ｜どこから持ってきたんですか。
朱司｜工事の見積もりの書類に、権現山《ごんげんやま》から取る、とあります。石柱から西へ五百メートルほどの、この丘です。
つむぎ｜山を削って、その土で海を埋めたわけですね。
朱司｜いまは山の上の平らなところが、小学校になっています。

### カット1-5 クエスチョン

地図: 標準地図 z17 に swale を重ねる / 台場の形に寄る

朱司｜できあがったのは翌年、1860年の夏です。
朱司｜大きさは、横がおよそ二百四十メートル、奥行きがまんなかで九十メートル近く。
つむぎ｜けっこう広いですね。
朱司｜まわりは石垣で囲まれていました。さて、ここでクエスチョンです。
朱司｜この石垣、海の底の岩盤から てっぺんまで、どれくらいの高さがあったでしょうか。
間｜3.2
つむぎ｜うーん……いま見えているのは、人の背丈くらいでしたよね。四メートルくらいでしょうか。
朱司｜もっとです。

### カット1-6 答え

写真: File:Kanagawa-daiba Stone wall.jpg

朱司｜答えは、二丈八尺。いまの単位で、八メートル半ほどです。
つむぎ｜八メートル半ですか。二階建ての家より高いですね。
朱司｜ほとんどは水の中と、いまは土の中です。
つむぎ｜じゃあ、いま見えている石垣は、上のほうだけですか。
朱司｜そういうことです。費用も書き残されていて、市史では六万両あまり。ただ、資料によって五万両から七万両まで開きがあります。

## 第2話 撃たない大砲

### カット2-1 大砲が並ぶ

地図: 標準地図 z16 に swale を重ねたまま

つむぎ｜大砲は、何門あったんですか。
朱司｜市史によると、佐賀の鍋島家《なべしまけ》が造った大砲を、幕府から十門借りています。
つむぎ｜海に向けて、ずらっと並べたんでしょうか。
朱司｜外国の船が入ってくる海に向けて、です。

### カット2-2 クエスチョン

地図: 淡色地図 z13 / 横浜港の入口から神奈川の海まで

朱司｜ではクエスチョンです。
朱司｜この台場から、敵の船に向けて撃った弾は、何発あったでしょうか。
間｜3.2
つむぎ｜幕末ですよね……。一回くらいは、撃ったんじゃないですか。
朱司｜答えは、ゼロです。

### カット2-3 礼砲

地図: 淡色地図のまま

つむぎ｜一発も撃っていないんですか。
朱司｜どの資料を見ても、戦いで撃った記録はありません。そのかわり、この台場からは、ずっと空砲を撃っていました。
つむぎ｜空砲というと、弾を込めずに音だけ出すものですよね。
朱司｜礼砲です。外国の王様の誕生日や、公使が船で着いたときに、あいさつとして撃ちます。
つむぎ｜お祝いのために撃つ大砲だったんですね。
朱司｜記録に残っている早い例は、明治元年の4月。イギリスの女王の誕生日でした。

### カット2-4 同じ数

地図: 淡色地図のまま

朱司｜明治5年、アメリカの軍艦から県に手紙が来ました。ワシントンの誕生日なので、昼の十二時に二十一発撃ちます、と。
つむぎ｜知らせてくるんですね。
朱司｜神奈川県令の返事が残っています。こちらも同じ日に、神奈川砲台で同じ数を撃ちます。
つむぎ｜二十一発撃たれたら、こちらも二十一発で返すんですね。
朱司｜外国とのつきあいの、決まりごとでした。

### カット2-5 やめられない

地図: 淡色地図のまま

朱司｜明治19年に、陸軍が礼砲をやめて、兵を引き揚げたいと言い出します。
つむぎ｜撃つたびに、お金もかかりますからね。
朱司｜ところが、イギリスの公使が異議を唱えました。それで、続けることになります。
つむぎ｜自分の国の台場なのに、よその国の都合で続いたんですか。
朱司｜それだけ、港の入口であいさつを交わすことが大事にされていた、ということです。
朱司｜台場が廃止されたのは、明治32年、1899年です。できてから三十九年でした。

## 第3話 陸に呑まれる

### カット3-1 まわりが埋まる

地図: 淡色地図 z15 / 神奈川宿の海岸線（swale を重ねる）

つむぎ｜廃止されたあとは、どうなったんですか。
朱司｜まわりの海が、少しずつ埋め立てられていきます。
つむぎ｜台場は、だんだん陸の一部になっていったんですか。
朱司｜大正の終わり、1924年には、台場の土地に土をかぶせて、貨物の駅が造られました。
つむぎ｜さっきの線路ですね。

### カット3-2 残してほしい

地図: 淡色地図のまま

朱司｜1936年の3月、郷土の歴史を調べていた人たちが、横浜市長に書類を出しています。
つむぎ｜何を頼んだんですか。
朱司｜台場を史跡として残して、埋め立てを止めてほしい、という願いです。
朱司｜その年の夏、市が台場を史跡にして、前の海の埋め立てをやめた、と新聞が伝えました。
つむぎ｜よかった。止まったんですね。

### カット3-3 クエスチョン

地図: 同じ画角で 明治の海（swale）→ 1945〜50年の空中写真へクロスフェード

朱司｜ではクエスチョンです。埋め立てをやめた、とされた台場の前の海。
朱司｜戦争が終わったころの写真で、そこは海のままだったでしょうか。
間｜3.2
つむぎ｜新聞に、やめたと出たんですよね。……海のままだと思います。
朱司｜見てみましょう。

### カット3-4 答え

地図: 1945〜50年の空中写真 z17 / 石柱の位置に印

つむぎ｜あれ。線路と、何かを積んである広場が見えます。
朱司｜台場の前も、もう陸になっています。
つむぎ｜止まらなかったんですか。
朱司｜戦争の前後に、前の海も埋め立てられました。昭和20年代の地図では、すっかり陸です。
つむぎ｜海の中に作った陸が、まわりの陸に呑まれてしまいました。

### カット3-5 標柱

地図: 1945〜50年 → いま の空中写真をクロスフェード

朱司｜1954年、開国百年の年に、横浜市はゆかりの場所に史跡の標柱を立てました。この台場の跡にも立てています。
つむぎ｜形はもう見えなくなっていたのに、立てたんですね。
朱司｜土の中に消えた台場があったことを、柱で知らせるためです。
朱司｜2002年には、市の教育委員会が試しに掘って、石垣がそっくり残っているところがある、と確かめています。
つむぎ｜埋まっているだけで、無くなってはいなかったわけですね。

## エンディング

### カット9-1 2026年

地図: シームレス空中写真 z17 / 石柱と東高島駅の北側

朱司｜いま、この線路の北側では、区画整理の工事が進んでいます。
つむぎ｜じゃあ、また掘ったんですか。
朱司｜去年の12月から掘って、今年の5月10日に、現地の説明会がありました。
朱司｜台場と陸をつないでいた道の石垣から、蛇籠《じゃかご》が出ています。
つむぎ｜じゃかご、ですか。初めて聞きました。
朱司｜石を詰めたかごです。川の護岸などで使います。台場から見つかったのは、ここが初めてでした。
つむぎ｜ほかの台場では見つかっていないものが、ここから出たんですね。
朱司｜ただ、その場所は新しい道路にかかります。現地には残さず、記録として残すことになりました。
つむぎ｜……見つかったところが、また見えなくなるんですね。

### カット9-2 変遷

地図: 同じ画角で 明治の海（swale）→ 1945〜50年 → いま の空中写真を順にクロスフェード

朱司｜もう一度、上から見てみましょう。明治の海。
つむぎ｜海の中に、さっきの形がありますね。
朱司｜戦争のあと。
つむぎ｜まわりが、もう陸になっています。
朱司｜そして、いま。
つむぎ｜線路と家ばかりです。形は、もうどこにも見えませんね。

### カット9-3 石垣

写真: File:Kanagawa-daiba.jpg（石柱と説明板、奥に石垣）

朱司｜できてから、百六十六年です。
つむぎ｜海の中に造られて、いまは陸の中に残っています。
朱司｜見えているのは、八メートル半のうちの、上の数段だけです。
つむぎ｜残りは、この足の下にあるんですね。
朱司｜ここはずっと、同じ場所にあります。変わったのは、まわりのほうでした。
