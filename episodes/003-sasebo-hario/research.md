# 第003回 佐世保市 針尾送信所 — 調査メモ

## 何があるか

3本の鉄筋コンクリートの塔。**1辺300メートルの正三角形**の頂点に立ち、
**その中心に電信室**がある。

| | |
|---|---|
| 高さ | 指定は**136m**（長崎県・佐世保市・文化庁）。Wikipedia は 1号135m / 2号135m / 3号137m と個別に書く |
| 基部の直径 | 12.1m |
| 壁の厚さ | 76cm |
| 塔の間隔 | 約300m、正三角形 |
| 電信室 | 耐爆構造・半地下式の2階建。内部に発電機室と送受信機室 |
| 指定範囲 | 無線塔3基・電信室1棟・油庫1棟・附 見張所1基・土地 44,285.74㎡ |

**高さの数字が資料で割れている。**指定文書は136mで揃っているので、
台本では「およそ136メートル」とし、個別値には踏み込まない。

## 話の核になりそうなもの

### 1. 塔は、電波を出していない

塔は**アンテナ線を吊るための支柱**で、電波を出すのは塔の上に渡した線のほう。
3方向（中国大陸・東南アジア・東京方面）に向けて張られていた。
送信機は東芝製、周波数 30kHz、出力 100kW の長波。

「塔が3本ある理由」を問うと、たいていは「大きいから」と答えたくなるが、
答えは「線を張るのに3点が要るから」で、**塔そのものは主役ではない**。
中心の電信室のほうが本体に近い。

### 2. 生コンもクレーンも無い時代に、136メートル

2020年の土木学会論文（小川健「1922(大正11)年に完成した重要文化財
『針尾無線塔』の施工方法の考察」土木学会論文集D2(土木史) 76巻1号 pp.32-50）
で施工方法が明らかになった。

- **外側の吊足場を上下に移動させながら**積み上げた
- **中練りコンクリートを搗き固める（搗固法）**で締め固めた
- 塩分の少ない川砂・砂利を使い、**布で拭いて**から打設した
- 砂とセメントは佐賀県唐津の松浦川から運び、何度も洗った

鉄筋コンクリートにした理由は「鉄材の高騰や潮風による腐食対策とされるが
詳細は不明」（Wikipedia）。断定しない。

### 3. 百年もった理由が、論文で分かっている

同じ論文が、**搗固法でできた緻密なコンクリートが中性化の抑制に有効**である
ことを検証している。つまり「丁寧に締め固めた」ことが、そのまま100年後の答えに
なっている。これが第3話の着地になる。

### 4. 有名な逸話は、たぶん違う

開戦の暗号電報「ニイタカヤマノボレ一二〇八」を発信した塔として紹介される
ことが多いが、**Wikipedia は「定かではない」とし、実際の送信は船橋送信所と
依佐美送信所であると考えられている**と書いている。

第001回で処刑地の理由を「よく言われるのは〜」と置いたのと同じ扱いにする。
否定して終わりにせず、「本当の値打ちは別にある」へ繋ぐ。

## 絵（タイル層の実測）

座標 33.06651, 129.75134 で確認済み。

| 層 | |
|---|---|
| 1945〜50年 空中写真 | **×** |
| 1961〜69年 空中写真 | **○** 3本の塔と影が写る |
| 1974〜78年 空中写真 | **○** 同上 |
| 1984〜86年 空中写真 | × |
| 現在のオルソ | **○** 塔と影。周囲はビニールハウス |
| 傾斜量図 | ○ |
| 陰影起伏図 | ○ |
| 明治期の低湿地 | ○（ただし塔の話には使いどころが無い） |
| 治水地形分類図 | × |
| 土地条件図 | × |

**この回の背骨は「1961 → 1974 → 現在」の三点**。
周囲は段々畑 → みかん畑 → ビニールハウスと3回入れ替わるのに、
3本の影だけが同じ位置にある。エンディングで効く。

なお現在のオルソは撮影時期の違う画像の継ぎ目が画面に入るので、
構図を決めるときに継ぎ目を避けるか、逆に見せないよう寄る。
