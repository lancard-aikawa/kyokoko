# 第005回 諫早 伊木力 —「石の下のガラス玉」 調査メモ

テーマ: **史跡**（4つ目のカテゴリ。遺構と発掘が芯）

最終更新: 2026-09-17

## なぜここか

**棄教したことになっている男の墓を掘ったら、キリシタンの副葬品が出てきた。**

千々石ミゲルは天正遣欧少年使節の4人のうち、ただ一人イエズス会を離れた人物として
知られている。帰国後は千々石清左衛門と名を変え、大村藩士として**キリシタン弾圧の側**
に立ったとされる。その墓が2003年に諫早市多良見町のみかん畑で見つかり、
2014〜2021年の4次にわたる発掘で、妻の棺から玉類とガラス板片が出た。

**墓石の表には「妙法」と刻まれている。**日蓮宗の題目である。
大村藩は主君・大村喜前が家門存続のため日蓮宗へ改宗した藩で、
ミゲル自身がその改宗を推し進めた側だった。
つまり地上の墓石は藩の宗旨のとおりで、地下だけが食い違う。

第003回（針尾送信所）で「ニイタカヤマノボレ」の真偽を扱ったのと同じ構えで、
**どちらが本当かは言わない。**「表と地下が食い違ったまま史跡になった」という
事実そのものを扱う。

そしてこの回は、地形テーマの第004回とは向きが逆になる。
第004回は土地が変わる話だったが、ここは**土地が何も変えられなかった**話になる。
ミゲルが与えられた600石の斜面は、いまもみかんの段々畑のままである。

### 第001〜004回との位置づけ

| 回 | テーマ | 芯 |

| 002 眼鏡橋 | 石碑 | 流されない橋が流された |

| 004 諫早湾 | 地形 | 土地のほうが変わる |
| **005 伊木力** | **史跡** | **掘るまで分からなかった** |

史跡テーマの型は「**掘る**」。石碑は読む、土木は寄る、地形はレイヤを差し替える。
史跡は**地面の下に何があるかを、地上の画で示せない**。ここが他の3つと違う。
だから画は「地上のいまの姿」と「発掘の記録（言葉と数字）」の二層になる。

**12月14日が三度出てくる。**没日（寛永9年12月14日）・墓石発見日（2003年12月14日）・
市史跡指定日（2024年12月14日）。没日は旧暦なので新暦の12月14日とは別の日で、
**指定日を命日の日付に合わせたと見るのが自然**だが、そう明記した資料は見つけていない。
**台本に「偶然」と書かないこと。**

**史跡の名称が「千々石清左衛門の墓」である。**ミゲルではない。
棄教後の名前で史跡になっている。市の解説も「千々石清左衛門ミゲルとその妻である
可能性が高い」と書き、断定を避けている。**この名前の付き方自体が締めに使える。**

天正遣欧使節4人のうち、**墓所が具体的に分かっているのはこの一人だけ**。

### 出土したもの

**1号墓（北側・女性・ミゲルの妻と推定）** — 第3次調査

- 埋葬形式: 石槨の中に**長持を転用した木棺**。**頭部を西に向け、南を向いた側臥屈葬**
- 二段掘りの墓壙。上段 2m四方・深さ40cm／下段 東西1.2m×南北1.6m・深さ80cm
- 木棺 長さ100cm×幅50cm×高さ50cm。礫で覆い、3枚の石材で蓋
- 人骨（大腿骨）と歯の一部。**35歳を中心に25〜45歳前後の女性**
- **ガラス玉59点**（白・青・紺・黒・琥珀色）
- **板ガラス片**（直径27mm）
- 布片（繊維片）
- 金属製品（錠前・蝶番・竿通し・釘）

**2号墓（南側・男性・ミゲル本人と推定）** — 第4次調査

- **木棺直葬**。1号墓と同じく**頭部を西に向け、南を向いた側臥屈葬**
- ほぼ全身の人骨
- **副葬品は報告書の抄録に明記が無い。**「ミゲル本人の墓からも信仰物が出た」とは
  書かないこと。**信仰物が出たのは妻の墓のほう**である

**「ロザリオ」と書かないこと。**報告書の表記は「玉類」「ガラス板片」「繊維片」で、
これらを「キリシタンの信仰物を副葬していた」と判断している。
ロザリオそのものと断定した記述は見ていない。字幕に出る語なので、
**報告書の言い方に合わせる**。

**頭位が西というのが効いている。**側臥屈葬は当時の在来の埋葬姿勢だが、頭を西へ
向けるのはキリシタン墓の特徴とされる。**姿勢は日本のやり方、向きは向こうのやり方**
という、それ自体が食い違った埋め方になっている。

## 「妙法」と戒名

| | |
|---|---|
| 墓石の刻銘 | 「妙法」の文字、男女二人の戒名、**寛永九壬申年十二月**（1632年12月＝没月） |
| 裏面 | 「千々石玄蕃允」（諫早市の解説は「千々石玄番」と表記。**資料で字が割れる**） |
| ミゲルの法名 | 本住院常安 |
| 妻の法名 | 自性院妙信霊 |

「妙法」は日蓮宗の題目。大村藩は初代藩主・**大村喜前**が、父・純忠のキリシタン時代から
一転して**家門存続のため日蓮宗へ改宗**し、1608年（慶長13年）に菩提寺・本経寺を建てた。
ミゲル＝千々石清左衛門は、その改宗を藩内で推し進めた側にいた。

**だから墓石は藩の宗旨どおりで、何も不自然ではない。おかしいのは地下だけである。**
ここがこの回の芯になる。

## 伊木力という土地

### みかん

- 伊木力でみかんの栽培が始まったのは**天明年間（1781〜89年）**、大村藩主・大村純鎮が
  苗木を植えさせたのが始まりとされる。以来230年余
- 土地に合う系統を選抜し続けて「**伊木力系**」が確立され、普通温州はこれに統一された
- 大村湾南岸の斜面が一面の段々畑になっている

**ミゲルの600石の斜面が、180年後にみかん畑になり、その畑の中から墓が出た。**
時間の並びがそのまま繋がるので、無理なく使える。

## 扱い方の方針

第002回（水害の死者）・第004回（開門問題）と同じ構えにする。

- **棄教したかどうかを断定しない。**プロジェクト側は「晩年まで信仰を保っていた
  可能性」を述べ、市の解説は可能性の表現に留めている。**番組も断定しない**
- 出土品は**報告書の語**で言う（玉類・ガラス板片・繊維片）。ロザリオと言い換えない
- 「隠れて信じていた」という筋書きを押し出さない。**表と地下が食い違っている**
  という事実を置いて、視聴者に預ける
- 宗教の当否には立ち入らない。**土地と遺構の話に戻す**
- 中浦ジュリアンの殉教と並べるのは一度だけ

## まだ確かめていないこと

- 墓所の正確な座標（現地実測ではなく掲載値）。構図を決める前に空中写真で取り直す
- 2号墓（ミゲル本人）の副葬品の有無。報告書の抄録に記載が無い。**本文を読む必要がある**
  （`sitereports.nabunken.go.jp/139803` から PDF が落ちる）
- **ミゲルの父がいつ死んだか。資料が三通りに割れている。**
  (a) 1577年の釜蓋城落城で父・直員が死んだ（もっともよく流通している話）
  (b) 直員は1570年（元亀元年）に横造城で自刃し、1577年に自刃したのは後嗣の澄員
  (c) 釜蓋城の記事は「千々石淡路守直員（ミゲルの父）」と「千々石大和守直員（養子）」
      を別人として書き、1577年に自刃したのは後者とする
  **台本では「城主は自刃した」までにして、父の死は書いていない。**
  ここを詰めるには『大村家記』など一次史料に当たる必要がある
- 諫早市の史跡指定日（12月14日）が命日に合わせたものかどうか
- 大村純鎮の読み（山川内は やまがわうち と確認済み）
- 伊木力ダムの着工年・総事業費・総貯水容量
- 墓石の寸法（「巨大な墓石」としか書かれていない資料が多い）
- 裏面の銘の字。「玄蕃允」（墓所調査プロジェクト）と「玄番」（諫早市）で割れている
- 伊木力公民館の展示「千々石ミゲル墓所発掘」の内容。現物の展示があるなら
  「いま見に行ける場所」として着地に使える

## 作ったあとに分かったこと（2026-09-17）

- **傾斜量図はこの土地で当たりだった。**z15 で段々畑の段が面で出て、谷を横切る
  ダムの堤体も黒い一本の線になる。ただし `slopemap` のズーム上限は 15 なので、
  寄りたいときは camera の scale で詰める（詰めすぎると master の拡大でぼやける）。
  実際の台本では scale 0.48〜0.70 に落ち着いた
- **`ort_old10` は上限 z17。**ダムの谷は z17 で撮ると 1961年も現在も native で出る
- **山川内の読みは やまがわうち。**日本郵便の郵便番号一覧（〒859-0415・
  タラミチョウヤマガワウチ）で確定した。VOICEVOX は ヤマカワナイ と読む。
  Wikipedia にも地図にも読みが無い地名は、ここで引くのが早い
- **単漢字の誤読を4つ踏んだ。**表（ヒョウ）・いちばん上（イチバンジョウ）・
  刷られた（ズラレタ）・空く（スク）。`readings.py` の `TRAPS` に足したので、
  次の回からは `check` が止める
- **`scan` を目で追っても2件落とした。**書き出した動画を聞いて見つかったのが
  「六百石」→ロッピャッセキ（石高の石は こく）と「墓所」→ハカショ。
  **どちらも scan の出力にそのまま出ていた。**130行のカタカナは目で流せてしまう。
  数える語（石・貫・俵）と墓・寺の用語は、声に出して確かめること。
  同じ聞き直しで「向いてる」→ムカイテル と「ローマ市民権」→ロオマシ・ミンケン も出た。
  前者は `TRAPS` に追加（`向《む》いてる` で通る）。後者は助詞を1つ入れて切った
  （ローマの市民権）
- **アウクスブルク版画は軸装ごと写っている。**右端に「天正遣欧使節肖像画
  濱田耕作氏寄贈」の題箋が入る。切ろうとして寄せると四人のどちらかの段が
  画面から切れるので、切らずにそのまま使った
