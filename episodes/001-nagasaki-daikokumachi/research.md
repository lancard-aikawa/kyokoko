# 調査メモ: 長崎市大黒町付近

対象: 長崎県長崎市大黒町（〒850-0057）および隣接する西坂町・筑後町・恵美須町・元船町・尾上町
調査日: 2026-09-15

## 地形の骨格

長崎は港に向かって「すり鉢状」。陸の際まで水深が深い＝良港である条件が、
そのまま「坂の町」の理由になっている。

長崎駅前（大黒町）は平地。その北東すぐに**西坂**の丘。この段差が全ネタの軸。
- 丘より上＝江戸期からの陸地
- 平地側＝明治の埋立地

## 埋立の年表

| 年 | 出来事 |
|---|---|
| 1591（天正19） | ポルトガル船長ベレイラの寄附でサン・ラザロ病院（ハンセン病）＋付属サン・ジョアン・バウチスタ教会が西坂の丘に建つ |
| 1597（慶長元）2/5 | 西坂で26人が処刑される |
| 1614（慶長19） | 幕府が「伴天連追放之文」を全国に公布（家康が発布し将軍秀忠が捺印）。これにより長崎と京都の教会が破壊される |
| 1620（元和6） | サン・ジョアン・バウチスタ教会跡に日蓮宗・本蓮寺が建立 |
| 1672（寛文12） | 旧恵美須町を分割して**大黒町**が誕生。恵美須・大黒の縁起による命名 |
| 1698（元禄11） | 五島町・大黒町一帯で大火 |
| 1882（明治15） | **第1次長崎港湾改修事業**。中島川の変流工事で大波止・大黒町沿岸を埋立 |
| 1897（明治30）〜7年間 | **第2次港湾改修事業**。鉄道を大黒町へ引くため埋立が急務に。軟弱地盤で難工事。この事業でほぼ現在の長崎の地形の骨格ができ、出島が陸続きになった |
| 1904（明治37） | 港埋立事業で台場町など10町が発足 |
| 1905（明治38）4/5 | **長崎駅**が大黒町に開業（仮駅舎）。日露戦争の軍需輸送円滑化が動機。旧長崎駅は浦上駅に改称 |
| 1910（明治43） | 大黒町が長崎くんちで**唐人船**を初奉納 |
| 1912（大正元）10/21 | 木造2階建て洋風駅舎が竣工 |
| 1945（昭和20）4/26 | 空襲。長崎駅2番ホームの列車に直撃弾、死者90名。駅舎半壊。出島岸壁・駅構内にも時限爆弾 |
| 1945（昭和20）8/9 | 原爆により駅本屋残部分が全焼 |
| 1956（昭和31） | 西坂が史跡に指定 |
| 1962（昭和37） | 列聖100周年。舟越保武の**日本二十六聖人記念碑**と記念館、今井兼次設計の聖フィリッポ教会が完成 |
| 1963（昭和38） | 住居表示。現在の大黒町は台場町1-4丁目・旧大黒町・西上町・西坂町・西中町・八千代町3丁目の各一部から発足（15街区） |

**注意**: 現在の大黒町の範囲は江戸期の大黒町と一致しない。駅に近い側はほぼ明治の埋立地。

## 碑・遺構

### 1. 日本二十六聖人記念碑（西坂町・西坂公園）
- 1597年2月5日、秀吉の禁教令によりフランシスコ会宣教師6人と日本人信徒20人が処刑
- 選ばれた理由: キリストが架けられたゴルゴタの丘に似ていると信者が願い出た／
  **"鶴の港"と称された長崎港が一望できる見晴らしのいい丘**（＝船で来る者への見せしめ）
- 1627・1629年に列福、1862年に列聖。1962年の列聖100周年に記念碑建立
- 制作: 舟越保武。花崗岩の台座・壁面に26人の等身大ブロンズ像を一列に並列
- **裏面は「長崎への道」** — 京都から長崎までの26人の旅を表現
- 2012年、日本カトリック司教協議会制定の唯一の公式巡礼所に

### 2. 「サン・ラゾロ病院 サンジョアン教会跡」碑（筑後町・本蓮寺門前）
- 1591年、入港したポルトガル船長ベレイラの寄附によるハンセン病のための病院
- 傍らに付属のサン・ジョアン・バウチスタ教会
- 1620年、教会跡地に日蓮宗・本蓮寺が建立
- 教会時代の名残として本堂右側の庭園に**南蛮井戸**が現存

### 3. 大黒町 — 碑がない町
- 長崎港の一番奥の船着き場。中国船（唐船）を繋ぐ入江として賑わった
- 1672年、恵美須町から分割。恵美須・大黒の縁起で命名
- その入江が埋め立てられ、1905年に長崎駅が立つ
- **海を失った5年後の1910年、大黒町は長崎くんちに「唐人船」を奉納し始めた**
- 演し物: 唐人船の長崎入港、接岸儀式、上陸、ボサ祭り（崇福寺へ航海無事の祈願）の再現、
  町娘と唐人の友好を表した踊。出港の儀式の後、唐楽に合わせて前進・後進を2度、
  楽器を早打ちとし前後進2度、右廻り左廻り右廻りと船を廻して退場

## 不採用

- **自然災害伝承碑**: 長崎市内の7基（川平町・鳴滝二丁目・矢上町・界二丁目・魚の町・
  船石町・浜町）はすべて1982年の長崎大水害関連で、中島川流域に集中。大黒町からは遠い
- **長崎街道の起点（札の辻）**: 位置と碑の実在を確認できず。要追加調査
